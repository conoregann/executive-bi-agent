# Contributing

This repository is optimized for autonomous and agent-assisted development.

All contributors and AI agents must follow the canonical instructions and invariants defined in [AGENTS.md](./AGENTS.md).

### Quick Commands
- Run verification: `pnpm check && pnpm test`
- Format code: `pnpm format:check`
- Base branches off `main` using `feat/<capability-name>` or `fix/<capability-name>`.
